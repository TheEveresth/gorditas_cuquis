# Preferencias de usuario

Directivas **personales** de quien trabaja en este repo (editor, hábitos, forma de responder).
Este archivo vive en la raíz como `PREFERENCIAS.md`, **no se versiona** (está en `.gitignore`)
y cada persona tiene el suyo. Los agentes lo leen cada sesión y lo aplican en silencio.

Reglas:

- Solo lo que depende del entorno o del gusto de una persona. Lo que aplica al proyecto va en
  `AGENTS.md`, en una skill o en `MEMORY.md`.
- Si una preferencia choca con `AGENTS.md`, gana el repo; el agente lo avisa en una línea.
- Una entrada = título con fecha + qué hacer.
- Los agentes **proponen** entradas; solo se agregan con el visto bueno de la persona.
